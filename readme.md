3. Nalezněte deset nejmladších zaměstnanců. Výsledek seřaďte od nejmladšího.
4. Vyberte křestní jména a příjmení zaměstnanců, kteří mají jako pohlaví `F`, a seřaďte je sestupně podle příjmení.
5. Najděte všechny zaměstnance, jejichž příjmení začíná na `A`.
6. Najděte a zobrazte všechny unikátní křesní jména seřazené podle abecedy.
7. Zobrazte všechny zaměstnance, kteří mají ID mezi 10001 a 10010.
8. Vyberte 5 zaměstnanců, začněte od 11. zaměstnance v tabulce, a seřaďte je podle ID zaměstnanců.
9. Najděte všechna unikátní křestní jména zaměstnanců, kteří se narodili v roce 1965.
10. Najděte všechny zaměstnance, kteří se narodili v prosinci jakéhokoli roku.
11. Najděte nejstaršího aktivního zaměstnance.
12. Vyberte všechna pole všech zaměstnanců, kteří mají jako pohlaví `M` a jejich ID je větší než 499999.
13. Seřaďte zaměstnance podle příjmení a zobrazte pouze jejich příjmení, ale bez duplicit.
14. Najděte všechny osobní čísla zaměstnanců, kteří jsou aktuálně zařazeni na seniorní pozici.
15. Zjistěte jaké osobní číslo zaměstnance pobírá aktuálně nejvyšší plat.
16. Najděte všechny osobní čísla zaměstnanců, kteří aktuálně vedou oddělení.
17. Zobrazte všechny zaměstnance, jejichž příjmení obsahuje řetězec `son`.
18. Vyberte křestní jména a příjmení zaměstnanců, kteří mají pohlaví `M` a seřaďte je podle data narození sestupně.
19. Vyberte 10 zaměstnanců, kteří mají nejnižší ID, a zobrazte pouze jejich ID a datum narození.
20. Najděte zaměstnance, kteří se narodili mezi lety 1980 a 1990 (včetně).
21. Vyberte první 3 zaměstnance, jejichž příjmení začíná na `K`.
22. Seřaďte všechny zaměstnance podle ID sestupně a vyberte pouze první 4 záznamy.
23. Vyberte všechna pole zaměstnanců, jejichž datum narození je starší než 1. ledna 1970, a seřaďte je podle data narození vzestupně.
