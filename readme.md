## SQL 01: SELECT

1. Do souboru `reseni.sql` definujte všechny SQL příkazy
2. Jakmile budete mít vypracovány všechny SQL příkazy, zobrazte výsledky dotazů uživateli ve formě tabulky.

## Obsah

1. Vyberte všechna pole všech zaměstnanců, kteří mají příjmení `Smith`.
2. Vyberte křestní jména a příjmení všech zaměstnanců, kteří se narodili po roce 1990.
3. Vyberte prvních 10 záznamů z tabulky `employees`, seřazených podle data narození vzestupně.
4. Vyberte křestní jména a příjmení zaměstnanců, kteří mají jako pohlaví `F`, a seřaďte je sestupně podle příjmení.
5. Najděte všechny zaměstnance, jejichž příjmení začíná na `A`.
6. Zobrazte všechny zaměstnance, kteří mají ID mezi 10001 a 10010.
7. Vyberte 5 zaměstnanců, začněte od 11. zaměstnance v tabulce, a seřaďte je podle ID zaměstnanců.
8. Najděte všechna křestní jména zaměstnanců, kteří se narodili v roce 1965.
9. Vyberte všechna pole všech zaměstnanců, kteří mají jako pohlaví `M` a jejich ID je větší než 499999.
10. Seřaďte zaměstnance podle příjmení a zobrazte pouze jejich příjmení, ale bez duplicit.
11. Najděte všechny osobní čísla zaměstnanců, kteří jsou aktuálně zařazeni na seniorní pozici.
12. Najděte všechny zaměstnance, kteří se narodili v prosinci.
13. Najděte všechny osobní čísla zaměstnanců, kteří aktuálně vedou oddělení.
14. Zobrazte všechny zaměstnance, jejichž příjmení obsahuje řetězec `son`.
15. Vyberte křestní jména a příjmení zaměstnanců, kteří mají pohlaví `M` a seřaďte je podle data narození sestupně.
16. Vyberte 10 zaměstnanců, kteří mají nejnižší ID, a zobrazte pouze jejich ID a datum narození.
17. Najděte zaměstnance, kteří se narodili mezi lety 1980 a 1990 (včetně).
18. Vyberte první 3 zaměstnance, jejichž příjmení začíná na `K`.
19. Seřaďte všechny zaměstnance podle ID sestupně a vyberte pouze první 4 záznamy.
20. Vyberte všechna pole zaměstnanců, jejichž datum narození je starší než 1. ledna 1970, a seřaďte je podle data narození vzestupně.
21. Najděte nejstaršího aktivního zaměstnance.
